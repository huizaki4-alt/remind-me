知識抽卡

載入緊…

相片只喺手機入面轉文字，唔會上載，轉完即刻丟棄，唔會儲存。第一次轉要下載辨識資料（約 16MB），之後離線都用得。

想更準：喺 iPhone「相片」App 長按相入面嘅字 →「拷貝」，再貼落上面。

加到主畫面

用 Safari 開呢頁 → 撳底部「分享」→「加至主畫面」。之後由主畫面圖示打開，先可以收通知。

備份

卡只存喺呢部手機。定期匯出備份，換機或者清咗資料都可以匯入返。

隨機卡通知

每日喺 9am 至 10pm 之間不定時推送一張隨機卡。由你自己 GitHub repo 嘅免費 Actions 負責發送，唔使錢。

最後一步（只做一次）：
  1. 喺 GitHub 開你個 repo →「Settings」→「Secrets and variables」→「Actions」
  2. 撳「New repository secret」，Name 填 PUSH_CONFIG，Secret 貼上設定碼，儲存
  3. 想即刻試：「Actions」→「隨機卡通知」→「Run workflow」
如果之後收唔到通知，返嚟呢度再撳「開啟通知」，再複製一次設定碼更新個 Secret。
